A server plugin for Simple Voice Chat that makes proximity voice chat realistic:
voices are muffled behind walls for every player, sound zones change how far a voice carries, and game rules decide who hears whom.

Players who also install the Voice Physics mod get the rest: distance curves, round corners, echo in caves, a HUD and a monitor.

 

✦ Walls — voices are muffled through walls, a whisper lost sooner than a shout. Load is capped, and on any error the original audio is sent, so voice chat never goes silent.

✦ Sound zones — a stage heard twice as far, a quiet library, a soundproof room, a cathedral with echo. Everyone sees the zone's name above the hotbar on entering.

✦ Realism (off by default) — dull voices under water, far voices covered by rain and thunder, echo in caves, wind high up, a quieter voice behind the speaker's back, and the Doppler effect.

✦ Player controls — /voice lets anyone talk quietly or shout, turn walls off for themselves, set other players' volume and see who is talking nearby. Clickable, with a menu and undo.

 

✦ Zones — draw a box in game with /vcd zone, use a whole world or a WorldGuard region.

✦ Game rules — sneaking is quieter, the dead are silent, spectators talk only to each other, a goat horn works as a megaphone.

✦ Fair play — offer or enforce the server's settings for players with the mod, turn off their monitor and radar so nobody sees through walls.

✦ Require the mod — send a download link, remind on every join, or kick.

✦ Mute — /vcd mute <player> [time] [reason], /vcd unmute, /vcd mutes.

✦ Admin tools — clickable /vcd commands with undo, a log of who changed what, /vcd debug <player> to see whom a player hears and why not, messages in each player's language.

✦ PlaceholderAPI — %vcd_mode%, %vcd_talking%, %vcd_zone% and more for scoreboards and tab lists.

✦ Extras (off by default, not yet tried in a live game) — a radio, loudspeakers, an eavesdrop item, a sculk reaction to shouts, doorway sound, Towny, Lands, WorldGuard and LuckPerms. /vcd extras lists them.

Admins with the mod change all of this in its Server tab.

 

1. Put voice-physics-bukkit-*.jar into plugins/. Simple Voice Chat must be installed.

2. Restart the server. Settings are in plugins/VoicePhysics/vc-audio-distance-server.properties, and all of them can be changed in game with /vcd.

Java 8+ (17+ on 1.18 and newer). Each part of /vcd has its own permission (vcd.status, vcd.settings, vcd.zone, vcd.debug, vcd.mute, vcd.speaker, vcd.admin); operators have all of them. Anonymous usage numbers go to bStats (no names, addresses or chat); metrics=false in the settings file turns it off.

Running Fabric, Forge or NeoForge? Install the mod on the server instead, it does all of this too.
